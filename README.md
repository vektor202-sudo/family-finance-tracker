# Family Finance Tracker

Приложение для совместного управления семейным бюджетом.

## Основной функционал
- **Доходы:** Категории (Зарплата Мужа, Зарплата Жены, Инвестиции).
- **Распределение:** Накопления и инвестиционный капитал.
- **Расходы:** Дата, сумма, пользовательские категории.
- **Аналитика:** Визуализация данных (графики, диаграммы).
- **Цели:** Финансовые цели (например, покупка жилья) с прогресс-баром в %.

## Стек технологий (предварительно)
